# Open questions and contradictions

Every contradiction or gap found between sources lands here **before** anyone
builds on it — requirement vs requirement, requirement vs design, requirement
vs existing code, docs vs code, practice vs config. One entry per question.

Close an entry by writing the answer, who gave it and when, then move the
outcome where it belongs: a requirement change, a code change, or an entry in
the decision log. Never delete an answered question; mark it ANSWERED.
